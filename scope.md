# AutoPatch AI - Project Scope

## In Scope (MVP)
- Real-time incident & error log ingestion.
- Autonomous AI analysis using LLM agents to pinpoint root causes.
- Automated patch generation and pull-request creation for quick remediation.
- Dashboard interface for SRE and engineering teams to review logs and actions.

## Out of Scope
- Direct production auto-deployment without human review.
- Support for legacy non-Git version control systems.
- Multi-region enterprise clustering.
